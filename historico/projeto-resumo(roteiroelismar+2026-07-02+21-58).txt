1. NOME E OBJETIVO DO PROJETO
- Nome: gestorderotas-elismar (roteiroelismar)
- Objetivo: Aplicação PWA para controle de rotas de visitas e agendamento de eventos voltada para vendedores externos de pet shop, com suporte offline-first e sincronização em nuvem com Firebase.

2. STACK TECNOLÓGICA
- Core: React + TypeScript + Vite.
- Estilos: Vanilla CSS + TailwindCSS (se aplicável, focado em classes utilitárias modernas).
- Banco e Serviços: Firestore (Firebase) para autenticação e sincronização na nuvem, localStorage para persistência offline.

3. FLUXO E FUNCIONAMENTO
- Tela de login autentica via Firebase Auth ou permite uso local (offline-first).
- Roteiros de visitas são gerados e calculados conforme frequência (semanal, quinzenal, etc.).
- Permite adicionar Visitas Extras diretamente à lista diária.
- Permite agendar Eventos e Compromissos na mesma data.

5. CONFIGURAÇÃO E EXECUÇÃO
- Instalação: npm install
- Desenvolvimento local: npm run dev
- Build de produção: npm run build
- Deploy: Firebase Hosting / Vercel
